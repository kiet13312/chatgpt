# Chat LGBT Game

A landscape Android game hub combining original mini-game modes:
- Garden Defense
- Fishing
- Scratchbetter Studio
- Survival, racing and quick mini-games

Built with native Android Java and Canvas. Progress is saved locally on the device.

The repository is the single combined project; older standalone projects are left untouched.

## Build
Run the **Build Android APK** GitHub Actions workflow, or from a machine with Android SDK installed:
```bash
gradle assembleDebug
```
APK output: `app/build/outputs/apk/debug/app-debug.apk`.
